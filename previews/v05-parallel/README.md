## 与上版的变化

- 本版以用户新提供的手形平行线参考为准，取消细腻油画贴图，直接以程序绘制粗平行曲线。
- 同一组连续线在形体上弯折，利用局部线距收紧/放宽表示浓淡；人物、街道基本轮廓由线场浮现。
- 运动来自关节姿态、体积和连续线场的变化；不靠人物整体缩放。
- 膝盖向前弯、手肘向后弯，分别求解并新增方向测试；不再使用带预置弯曲姿势的绘画肢体。
