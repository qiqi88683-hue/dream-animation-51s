# 美术方向修正 v0.2：油画与素描之间

本轮依据用户反馈重做：密集、沿形体流动的曲线排线，用疏密和交叠表现颜色浓淡；深沉的油画颜料感；男主高但不异常突出，人体比例自然。

**下面两张是生成的静态美术方向图，不是已经实现的新动画。** 颜色、人物普通感与笔触仍待确认；v0.1平涂矢量风格已被否定。
