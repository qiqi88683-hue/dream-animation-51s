# 51 秒梦境二维动画｜Codex 项目交接包

> 当前状态：**仅完成需求交接与工作流设计；用户尚未授权开始编写视频代码。**

## 从 Mac 开始

1. 把这个文件夹完整保存到 Mac 上，不要只取出 Word 文档。建议文件夹名保持为 `dream-animation-51s`。
2. 打开 ChatGPT 桌面版中的 **Codex**（或者 Codex for macOS），创建/选择项目，并打开这个文件夹作为工作目录。不同版本的菜单名称可能略有不同。
3. 在 Codex 的新对话中粘贴根目录的 `CODEX_START_PROMPT.txt` 内容。
4. 先让 Codex **只阅读、梳理和确认需求，不生成代码**；确认一切准确后，你再发送明确的“开始代码制作”指令。
5. 如果要在 **Codex Cloud** 中运行，需要把本文件夹纳入可供云端访问的项目仓库（例如私人 GitHub 仓库），连接并发布 Cloud 环境；只放在 Mac 本地的文件夹不会自动出现在 Cloud。建议避免公开上传包含个人创作的素材。

## 文件用途

- `AGENTS.md`：Codex 会读取的持续项目指令；先看这个。
- `PROJECT_SPEC.md`：详细创作要求，区分用户已确认内容与技术建议。
- `SHOTLIST.md`：七镜头的**原文转录**、时间、台词和音效，始终以 `source/视频分镜设计表 (1).xlsx` 为最终原始依据。
- `AUDIO_PLAN.md`：声音分层、音量自动化及电话/拒接剧情处理。
- `PROGRESS.md`：可续做进度记录模板，目前全部为未开始。
- `CODEX_START_PROMPT.txt`：首次与 Codex 对话时可直接粘贴的文字。
- `source/`：两份用户原始附件，均完整保留；场景 Word 文档内含两张示意图。

## 重要说明

这不是一份已经实现的视频工程，没有程序依赖和渲染成品。**不要把方案视为用户已经批准的最终风格样片。**

推荐技术栈：Remotion / React / SVG 为主，必要时用 Three.js 辅助第一镜的摄影机转换，音效处理与导出可用 FFmpeg。技术栈只是当前建议，可以在小样验证后调整。

## 需求优先级

1. 用户未来在 Codex 中直接给出的新指令。
2. 用户在本轮对话中更新的明确要求（已记录于 `PROJECT_SPEC.md`）。
3. 两份原始上传文件（逐镜头内容和人物、环境连续性细节）。
4. 以“建议”“可考虑”表达的创意与技术提案（非硬性要求）。

存在冲突时，不要无声覆盖：先确认最新明确要求，必要时记录待确认事项。
